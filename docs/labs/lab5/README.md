# Лабораторная работа 5: прототип GremlinDrive

Работа выполнена по актуальному заданию №575. Оценки палитр - открытое учебное моделирование десяти профилей, не опрос реальных людей. В каждой строке semantic.csv указан источник synthetic.

[Отчёт](lab5-report.pdf), [исходный текст](REPORT.md), [прототип](prototype/index.html), [руководство по стилю](prototype/styleguide.html).

Для локального запуска из docs/labs: `python3 -m http.server 8056`, затем открыть http://127.0.0.1:8056/lab5/prototype/. Параметр `mobile=1` включает мобильную навигацию на планшете. Параметр `theme=green` или `theme=plum` меняет палитру. Параметр `screen=files` открывает список для просмотра макетов. Авторизация демонстрационная; реальные реквизиты вводить не нужно.

Прототип поддерживает папки, поиск, избранное, ссылки, корзину и версии. Он сохраняет только демонстрационные метаданные в localStorage; сервер и реальные файлы не подключены. Восстановление версии меняет отметку текущей версии. «Сбросить демо» возвращает исходный набор.

В assets сохранены шесть веб-размеров, пять мобильных размеров и три палитры на двух платформах. capture.html задаёт размер внутреннего iframe; масштабирование рамки не меняет CSS-раскладку. Измерения ширины и кнопок: ../lab6/data/layout-checks.json.

Расчёты повторяются командой `python3 scripts/model_study.py` (нужен matplotlib). Проверка: `python3 ../lab6/scripts/verify.py`. Генератор с фиксированным seed 20261024 обновляет связанные данные обеих работ. Построение листов изображений: scripts/prepare_assets.py; текстов: scripts/write_reports.py; PDF: scripts/build_reports.py (ReportLab и системные Times New Roman на macOS).

Публичная страница: https://fpmi-hci-2026.github.io/GremlinDrive/labs/lab5/.
