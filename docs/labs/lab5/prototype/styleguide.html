Фон #F6F8FC, поверхность #FFFFFF, выделение #EDF2FF, граница #E6EAF1. Состояние обозначается текстом, значком и цветом вместе. Ошибка: #B42318 с пояснением под полем.

Типографика и сетка

Системный стек: -apple-system, BlinkMacSystemFont, Segoe UI, sans-serif. Заголовок web 34 px, mobile 29 px; текст 14-16 px, подпись 12 px. Шаг отступов 4 px: 8, 12, 16, 24, 32, 40. Радиус поля 10 px, карточки 14 px.

Мобильная версия на планшетах сохраняет нижнюю навигацию через параметр mobile=1. Диалог не шире экрана и имеет собственную прокрутку.

Действия и состояния

Основное действие одно на область. Удаление сопровождается подтверждением и восстановлением из корзины. Загрузка в прототипе добавляет метаданные, содержимое файла никуда не передаётся.

Обязательное поле не принимает пустое название; дубликат показывает встроенное сообщение проверки. Пароль ссылки: минимум 8 символов, если заполнен. Срок по умолчанию: 7 дней.

Кнопки и поля имеют высоту от 44 px. Tab перемещает фокус, Enter отправляет форму, Escape закрывает диалог. Фокус - контур 3 px с отступом. Для уведомлений используется role=status, для окон - native dialog. Анимация отключается при prefers-reduced-motion.
