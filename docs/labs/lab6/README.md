# Лабораторная работа 6: оценка прототипа

Проверяется тот же GremlinDrive, что и в ЛР5, с навигацией ЛР2 и UC-01-UC-05 ЛР3. [Отчёт](lab6-report.pdf), [текст](REPORT.md), [анкеты](QUESTIONNAIRES.md), [дерево](tree.html), [формы](forms.html).

Модельная часть: 15 профилей, 210 попыток для 7 задач на двух платформах, 30 SUS, 120 выборов дерева, 120 оценок ожиданий. Эти данные синтетические. PROVENANCE.json и исходные CSV сохраняют происхождение; реальных сессий не было. 12 моделей GOMS и 3 мобильные KLM - аналитические оценки.

Фактическая проверка интерфейса записана отдельно: data/prototype-checks.json, data/layout-checks.json (11 размеров), data/contrast.csv. Деревья web и mobile различаются, как в исходной ЛР2. Treejack не запускался: подготовлены импорт и задания для отдельного исследования.

Независимая проверка без внешних пакетов: `python3 scripts/verify.py`. Генератор: ../lab5/scripts/model_study.py. Публичная страница: https://fpmi-hci-2026.github.io/GremlinDrive/labs/lab6/.
