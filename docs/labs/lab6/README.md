Пользовательская часть - синтетическое моделирование десяти профилей. Реального исследования с людьми не было. Фактическая техническая проверка интерфейса описана отдельно от модели.

[Отчёт](lab6-report.pdf), [исходный текст](REPORT.md), [анкеты и протокол](QUESTIONNAIRES.md), [локальный тест дерева](tree.html), [варианты форм](forms.html).

PROVENANCE.json фиксирует происхождение. Модели времени - аналитические оценки, не измерение пользователей.
