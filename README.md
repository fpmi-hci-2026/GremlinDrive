# GremlinDrive

GremlinDrive — проект безопасного облачного хранилища для личной и командной работы. Продукт объединяет веб-приложение и мобильный клиент и помогает хранить, находить и передавать файлы без хаоса в мессенджерах и почтовых вложениях.

> **Ваши файлы. Ваши правила.**

## Что планируется

- файловый менеджер с папками, поиском, предпросмотром и корзиной;
- публичные ссылки с паролем и сроком действия;
- роли доступа и совместная работа с историей версий;
- офлайн-доступ и автозагрузка фото в мобильном приложении;
- двухфакторная аутентификация, аудит и панель администратора;
- развёртывание на собственной инфраструктуре.

## Репозитории проекта

Курс предусматривает четыре отдельных репозитория:

1. **Основной репозиторий** — документация, материалы лабораторных работ и GitHub Pages (этот репозиторий).
2. **Backend/API** — серверное приложение и REST API.
3. **Web** — веб-клиент.
4. **Mobile** — мобильный клиент для Android и iOS.
